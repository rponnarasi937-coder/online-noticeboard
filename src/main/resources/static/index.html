About KEC Online Notice Board

Instant, Paperless Campus Communication

Designed specifically for Kongu Engineering College (KEC), this modern centralized notice repository ensures students, staff, and faculty never miss an essential deadline. From exam schedules to multi-million package campus drives, everything is published securely with role-based administrative control.

  • ✓ 100% Mobile and Tablet Responsive
  • ✓ Categorized & Filterable Search
  • ✓ Downloadable Official PDF Circulars
  • ✓ Secured with Spring Security & BCrypt Password Hashing

Project Architecture

Frontend: Vanilla HTML5, CSS3, Modern JS
Backend: Java Spring Boot 3.3 (REST APIs)
Database: MySQL / Hibernate JPA
Security: JWT + BCrypt Hashing
Admin Credential: admin / admin123
